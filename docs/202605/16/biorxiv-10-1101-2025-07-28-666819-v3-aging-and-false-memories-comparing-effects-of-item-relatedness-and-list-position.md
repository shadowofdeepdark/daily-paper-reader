## 摘要
经典的系列位置曲线的证据表明，语义性虚假记忆通常源自被认为是长期记忆储存，而音位性虚假记忆则源自被认为是短期记忆储存。然而，近期对年轻成年人的研究对这一区分提出了挑战，发现语义性和音位性虚假记忆可以在不同的记忆储存和列表位置上出现（Atkins & Reuter-Lorenz, 2008；Dimsdale-Zucker 等, 2018；Flegal 等, 2010）。本研究旨在检验语义性与音位性虚假记忆是反映不同还是共享的潜在机制，以及这些模式是否随年龄而异。年轻成年人（YAs）和老年成年人（OAs）完成了一个改进的 Deese-Roediger-McDermott 范式，该范式在列表位置上操控语义和音位相似性。尽管老年成年人回忆的项目少于年轻成年人，但两组都产生了比语义性虚假记忆更多的音位性虚假记忆。值得注意的是，列表位置对年轻或老年成年人的虚假记忆均无影响，这表明虚假记忆的生成更多取决于列表构成，而非假定的记忆储存。这些发现通过揭示跨越传统记忆系统划分的共享认知过程，挑战了传统的记忆组织观念。

## Abstract
Evidence from classic serial position curves suggests that semantic false memories traditionally arise from presumed long-term memory stores whereas phonological false memories arise from presumed short-term memory stores. However, recent research with younger adults challenges this distinction, finding semantic and phonological false memories across memory stores and list positions (Atkins & Reuter-Lorenz, 2008; Dimsdale-Zucker et al., 2018; Flegal et al., 2010). The present study tested whether semantic and phonological false memories reflect distinct or shared underlying mechanisms and whether these patterns differ with age. Younger (YAs) and older (OAs) adults completed a modified Deese-Roediger-McDermott paradigm that manipulated semantic and phonological similarity across list position. Although OAs recalled fewer items than YAs, both groups generated more phonological than semantic false memories. Notably, list position did not influence false memories in either YAs or OAs, suggesting false memory generation is driven by list composition rather than putative memory store. These findings challenge traditional views of memory organization by revealing shared cognitive processes, which transcend traditional memory system distinctions that underlie semantic and phonological false memories.
