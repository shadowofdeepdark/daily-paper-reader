## 摘要
语音大型语言模型（Speech Large Language Models，SLMs）通常基于文本大型语言模型（Text Large Language Models，TLMs）的检查点构建，但它们仍然存在显著的模态差距。以往研究主要尝试从输出端入手，通过使语音生成更接近文本生成来缩小这一差距，但问题依然存在。我们认为，剩余的关键瓶颈在于输入端。为此，我们提出了 TextPro-SLM，这是一种使语音输入更接近具有韵律感知能力的文本 LLM 的模型。TextPro-SLM 将 WhisperPro——一种能够生成同步文本 token 和韵律嵌入的统一语音编码器——与 LLM 主干相结合，该主干在保持原始 TLM 语义能力的同时学习副语言（paralinguistic）特征理解。实验结果表明，TextPro-SLM 在 3B 与 7B 两种规模下的领先 SLM 中均实现了最小的模态差距，并在副语言理解任务上表现出强劲的整体性能。这些性能提升仅依赖约 1000 小时的 LLM 训练音频即可实现，这表明，从输入端减少模态差距既高效又数据利用率高。

## Abstract
Speech large language models (SLMs) are typically built from text large language model (TLM) checkpoints, yet they still suffer from a substantial modality gap. Prior work has mainly attempted to reduce this gap from the output side by making speech generation more text-like, but the gap remains. We argue that the key remaining bottleneck lies on the input side. We propose TextPro-SLM, an SLM that makes spoken input more closely resemble that of a prosody-aware text LLM. TextPro-SLM combines WhisperPro, a unified speech encoder that produces synchronized text tokens and prosody embeddings, with an LLM backbone trained to preserve the semantic capabilities of the original TLM while learning paralinguistic understanding. Experiments show that TextPro-SLM achieves the lowest modality gap among leading SLMs at both 3B and 7B scales, while also delivering strong overall performance on paralinguistic understanding tasks. These gains are achieved with only roughly 1,000 hours of LLM training audio, suggesting that reducing the modality gap from the input side is both effective and data-efficient.

## 一、研究动机与核心问题

- **背景**：  
  当前的语音大语言模型（Speech LLM，简称 SLM）通常通过在文本大语言模型（Text LLM，简称 TLM）上进行增量训练来获得听说能力，但存在显著的“模态差距”（modality gap）——即同样的任务在语音输入条件下表现明显劣于文本输入。  
- **问题**：  
  以往研究主要从输出端进行优化（如改进语音生成模块或解耦“思考-发声”架构），但输入端仍存在瓶颈：语音输入在传递给 LLM 时难以被高效地表示，LLM 无法同时理解语义内容与韵律特征。  
- **核心目标**：  
  作者提出从**输入端**减少模态差距，使语音输入尽可能接近文本输入，同时保留副语言特征（如语气、情感、说话方式），从而提升语义理解与语音任务表现。

## 二、方法论：TextPro-SLM 框架

### 1. 总体思想
从语音输入的表征方式入手，构建一个“**具备韵律感知的文本大模型**”，使输入端同时显式包含语义与韵律信息。  
提出的 **TextPro-SLM** 包含两个关键组件：

1. **WhisperPro 编码器**：生成同步的文本 token 与韵律（prosody）嵌入。  
2. **LLM 主干模型**：在保持原文本 LLM 语义能力的同时学习副语言特征理解。

### 2. WhisperPro 结构
- 基于 **Whisper-large-v3** 构建，保留 32 层 Transformer 编码器与解码器。
- 关键输出：
  - 文本 token（语义流）
  - 与每个 token 对齐的韵律嵌入（prosody embedding）
- **训练目标函数**：
  - ASR损失（交叉熵）：
    \[
    L_{ASR} = -\frac{1}{N}\sum_{i=1}^N \log p(y_i^*|y_{<i}^*, M)
    \]
  - Mel重建损失（均方误差）：
    \[
    L_{mel} = \frac{1}{FL} \| \hat{M} - M \|_2^2
    \]
  - 总损失：
    \[
    L = L_{ASR} + \lambda L_{mel}, \quad \lambda = 1.0
    \]
- 训练集：LibriSpeech (960小时) + CommonsenseQA 语音版 (40小时) → 合计约1000小时。

### 3. LLM 主干设计
- 基于 **Qwen2.5-3B/7B-Instruct**。
- 两阶段训练：
  1. 冻结 LLM，仅训练韵律投影器；
  2. 联合微调 LLM 与投影层，以适配语音输入。
- **输入形式**：
  - 全局前置：将句子的韵律嵌入平均得到一个向量并插入文本序列开头；
  - 交错插入：按固定比例在文本 token 间插入压缩韵律向量。
- 训练目标：
  - 语义保持（知识蒸馏从 TLM 教师模型获得）；
  - 副语言理解（情感、性别、年龄、口音等多任务学习）。

## 七、优点与创新

- **输入端创新视角**：首次系统性提出从输入模态减少语音与文本差异，而非仅优化输出端。
- **双流表征**：显式分离“语义流”与“韵律流”，兼顾语言与副语言信息。
- **架构兼容性强**：设计保持 LLM 输入格式、推理过程与文本模型一致；迁移更容易。
- **数据效率高**：相比其它端到端语音模型所需上万小时语音，仅需约千小时即可实现同等级或更佳性能。
- **全面验证**：包括模态差、推理、情感等多指标，并有系统消融。
