## 摘要
语音大型语言模型（SLM）通常基于文本大型语言模型（TLM）的检查点构建，但它们仍然存在显著的模态差距。以往的研究主要尝试从输出端减小这一差距，通过使语音生成更接近文本形式，但差距依然存在。我们认为，关键的瓶颈仍然在输入端。我们提出了 TextPro-SLM，这是一种使语音输入更接近韵律感知型文本 LLM 的 SLM。TextPro-SLM 将 WhisperPro（一个能够生成同步文本标记和韵律嵌入的统一语音编码器）与一个在保持原始 TLM 语义能力的同时学习副语言理解的 LLM 主干相结合。实验结果表明，TextPro-SLM 在 3B 和 7B 规模下都实现了领先的 SLM 中最低的模态差距，同时在副语言理解任务上表现出色。这些提升仅使用了约 1000 小时的 LLM 训练音频，表明从输入端减小模态差距既有效又数据高效。

## Abstract
Speech large language models (SLMs) are typically built from text large language model (TLM) checkpoints, yet they still suffer from a substantial modality gap. Prior work has mainly attempted to reduce this gap from the output side by making speech generation more text-like, but the gap remains. We argue that the key remaining bottleneck lies on the input side. We propose TextPro-SLM, an SLM that makes spoken input more closely resemble that of a prosody-aware text LLM. TextPro-SLM combines WhisperPro, a unified speech encoder that produces synchronized text tokens and prosody embeddings, with an LLM backbone trained to preserve the semantic capabilities of the original TLM while learning paralinguistic understanding. Experiments show that TextPro-SLM achieves the lowest modality gap among leading SLMs at both 3B and 7B scales, while also delivering strong overall performance on paralinguistic understanding tasks. These gains are achieved with only roughly 1,000 hours of LLM training audio, suggesting that reducing the modality gap from the input side is both effective and data-efficient.

- **现有问题**：以往研究主要从**输出端**（speech generation）优化，如通过引入中间文本层、解耦“思考-发声”架构等，使输出更趋近文本形式，但差距依然存在。
- **提出观点**：作者认为剩余瓶颈主要在**输入端**——SLM接收到的语音表示形式与TLM原生文本输入存在认知和形式上的不匹配。
- **核心目标**：通过使语音输入在语义和结构上更接近文本输入，同时保留韵律（prosody）和副语言信息，从而从输入侧最小化模态差距。

## 二、方法论：TextPro-SLM 框架

### 1. 总体思想

TextPro-SLM 的总体目标是**让语音 LLM 行为上尽可能接近一个具备韵律感知的文本 LLM**。实现路径是将语音输入显式分解为：
- “**说了什么**” → 文本标记（text tokens）；
- “**怎么说的**” → 韵律嵌入（prosody embeddings）。

### 2. 模型结构

#### （1）WhisperPro：语音编码器
- 基于 **Whisper-large-v3** 改进而来；
- 关键创新：输出**同步的两条流**：
  - **文本流（text tokens）**：由标准ASR生成；
  - **韵律流（prosody embeddings）**：从Whisper解码器中层（第16层）提取，与每个文本token对齐；
- 加入一个**Mel 重构器（mel reconstructor）**，通过重建原始mel谱图的任务迫使模型保留韵律特征；
- 多任务联合训练目标：
  \[
  L = L_{ASR} + \lambda L_{mel},  \quad \lambda=1.0
  \]
  其中 \(L_{ASR}\) 为交叉熵文本识别损失，\(L_{mel}\) 为Mel重建误差。

#### （2）LLM 主干：韵律感知 LLM
- 基于 **Qwen2.5-Instruct系列**（3B & 7B）。
- 目标：既保持原始TLM的语义能力，又具备对韵律、副语言特征的理解。
- 输入设计：
  1. **全局预置（Global Prepending）**：将整句韵律嵌入通过平均池化汇总为单向量，作为一个“前置token”插入文本输入前。
  2. **交替插入（Interleaving）**：在文本序列中周期性地插入压缩过的韵律向量，以捕获句内韵律变化。
- 训练阶段采用两阶段策略：
  1. 固定LLM，仅训练韵律嵌入投影器；
  2. 联合微调LLM与投影器。

#### （3）知识蒸馏与副语言训练
- **语义保持**：从TLM教师模型蒸馏语义能力；输入通过TTS合成的语音后经WhisperPro处理。
- **副语言学习**：通过情感（SER）、年龄（AGE）、性别、口音等任务增强LLM的韵律理解。
- 多任务数据集（总计约1000小时语音）见下。

## 六、主要结论与发现

1. **模态差距显著下降**：  
   TextPro-SLM 在 3B/7B 模型上均取得最低平均模态差距（7B版平均差距仅 0.7%），优于 SALAD (7.1%) 与 Qwen2.5-Omni (3.1%)。
2. **语义保真与推理增强**：  
   在涉及复杂推理的任务（如VoxEval数学推理）中仍显著领先。
3. **韵律与副语言理解提升**：  
   在情感、性别、年龄、口音等任务上保持最强表现（平均64.8%），说明能有效利用韵律信息。
4. **数据效率优异**：  
   仅约1000小时音频即可超越多款10倍以上数据规模的SLM。
5. **输入端对齐优于输出侧优化**：  
   验证了“输入端改进可有效弥合模态差距”的假设。
